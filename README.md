## Flagship project

### [nami — AI-assisted portfolio stress testing](https://github.com/ignitesplash101/nami)

[**Try the live application**](https://nami-wy4mdlp7hq-an.a.run.app) ·
[**Read the methodology**](https://github.com/ignitesplash101/nami/blob/main/docs/methodology.md)

Nami turns a hypothetical market scenario into a transparent portfolio stress
analysis. It combines grounded scenario research, historical analogs, a
factor-based quantitative engine, and position-level attribution in an
answer-first web application.

- Separates LLM-generated market interpretation from deterministic portfolio math.
- Replays historical events and surfaces evidence, uncertainty, and model limits.
- Supports backdated analysis, benchmarks, saved portfolios, exports, and live run progress.
- Includes production controls for cost, rate limits, observability, accessibility, and responsive UX.

`Python` · `FastAPI` · `React` · `TypeScript` · `NumPy` · `GCP` · `Docker`
